# Release Notes

## Version 1.0

**Release Date:** 16 June 2026

### New Resources Added

#### Excel Tracking Spreadsheet

A new Google sheet (saved in Excel format) based tracking spreadsheet has been added to support users who wish to record their daily measurements and outcomes in a simple, structured format.

Features include:

* Daily weight recording
* Weekly summaries
* Weight goal calculations
* Outcome tracking against personal targets
* Long-term measurement and review support

The spreadsheet is provided as a practical tool to support awareness and consistency rather than strict monitoring or compliance.

#### README Guide

A new `README.txt` guide has been added to accompany the spreadsheet and explain the underlying approach.

Topics covered include:

* How to use the tracking spreadsheet
* Morning and evening weight measurements
* The concept of Rested Weight
* Weekly and monthly review cycles
* Goal setting and expected outcomes
* The Measure → Learn → Adapt framework

The guide is intended to help users understand not only how to record information, but also how to interpret patterns and make informed adjustments over time.

### Purpose

These additions provide a complete starting toolkit for individuals who wish to explore weight management through observation, reflection, and gradual adaptation.

The focus remains on building awareness, understanding personal patterns, and supporting sustainable long-term change.
